Zomato Restaurants Analysis | Power BI

Project Overview

This project analyzes Zomato restaurant data using Microsoft Power BI to explore restaurant ratings, customer votes, approximate cost, online ordering, and table booking.

Tools Used

- Microsoft Power BI
- Data visualization
- Charts and KPI cards

Dashboard Highlights

- Total restaurant count
- Restaurant ratings and customer votes
- Online order availability analysis
- Table booking analysis
- Approximate cost analysis
- Visual comparison of restaurant metrics

Objective

To transform restaurant data into meaningful visual insights that help understand customer preferences and restaurant trends.

Project File

The Power BI dashboard is available in this repository as "zomato_Restaurant_Analysis.pbix".
